# HWHS Exam & Coding Portal v4.0

This is the official High-Fidelity Exam and Coding Studio portal for **Holy Writ High School & Junior College**, developed by **Deepak Kumar (Robotics & AI)**.

## Core Features

- **Advanced Coding Studio**: Supports Python and HTML/CSS execution with a professional Night Mode IDE.
- **20 Professional Problems**: Curated curriculum for Class XI/XII Science & Commerce with 200+ line enterprise solutions.
- **Virtual AI Teacher**: A multilingual, Gemini 1.5 Pro powered assistant identifying as Mr. Deepak Kumar.
- **Proctored Exam Engine**: Fullscreen enforcement, tab-switch detection, and real-time proctoring for Computer & Robotics exams.
- **Official OMR Generator**: Precision-engineered A4 print templates for physical answer sheets.
- **Automated Reporting**: All submissions are automatically formatted and emailed to the faculty for evaluation.

## Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS & ShadCN UI
- **AI**: Google Genkit with Gemini 1.5 Pro
- **Communication**: Nodemailer for secure exam dispatch
- **Storage**: Local-First architecture with high-fidelity state management

## Deployment

This project is optimized for deployment on platforms like Vercel or Firebase Hosting. Ensure environment variables for `GMAIL_USER` and `GMAIL_APP_PASSWORD` are configured for the email service.
